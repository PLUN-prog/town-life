SYNC云端同步

把小镇数据存到你的 GitHub（私有 Gist）。手机 / 电脑 / 朋友输入同一把密钥，就能互通同一份数据。

未连接。密钥在哪拿？点下方「如何获取密钥」。
自动同步（页面打开时每 2 分钟）
1. 浏览器打开 github.com → 头像 → Settings → Developer settings → Personal access tokens → Tokens (classic)
2. 点 Generate new token (classic)，勾选 gist 一项即可
3. 点最下方 Generate token，复制 ghp_ 开头的密钥，粘贴到上方
4. 点「连接」；其他设备（手机/朋友）输入同一把密钥即可互通同一份数据
⚠️ 密钥 = 小镇钥匙：拿到它的人能读写你的小镇数据，只发给信任的人。
